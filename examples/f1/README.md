# F1 illustrative data

This directory contains a small, sanitized evidence package corresponding to
the F1 workflow in the paper. It is provided so that reviewers can inspect the
format of the reported message statistics and the public NGSetupRequest seed.
It is not the complete experiment archive and should not be interpreted as a
full reproduction of the reported campaign.

* `base/message_stats_base.txt` is the baseline summary.
* `comp/message_stats_comp.txt` is the knowledge-guided comparison summary.
